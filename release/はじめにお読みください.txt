============================================================
  Voice Input Studio  ご利用ガイド
  （PC全体で使える音声入力アプリ）
============================================================

このアプリは、マイクに話した内容を自動で文字にして、
今カーソルがある場所（メール・Word・チャットなど）に
そのまま入力してくれるソフトです。

────────────────────────────────────────────
■ 必要なもの
────────────────────────────────────────────

・Windows 10 または 11 のパソコン
・マイク（ノートPC内蔵マイクでもOK）
・以下2つの「APIキー」（後述の手順で無料〜少額で取得できます）
    - OpenAI のキー … 音声を文字にする（聞き取り）ために使用
    - Google Gemini のキー … 文章を整える（句読点・誤変換修正）ために使用

※APIキーは「あなた専用のパスワードのようなもの」です。
  このアプリはあなたのキーを使ってあなたのアカウントで動きます。
  （作った人の費用はかかりません／あなたの利用分だけ課金されます）


────────────────────────────────────────────
■ ステップ1：アプリを起動する
────────────────────────────────────────────

1. 受け取った ZIP ファイルを「すべて展開（解凍）」する
   ※ZIPの中身のまま実行せず、必ず一度フォルダに解凍してください
   ※デスクトップやドキュメントなど、書き込みできる場所に置いてください
     （Program Files など特別な場所だと自動更新ができません）

2. 中の「VoiceInputStudio.exe」をダブルクリック

3. 青い画面で「WindowsによってPCが保護されました」と出たら
   →「詳細情報」をクリック →「実行」をクリック
   （個人で作ったアプリのため出る警告です。問題ありません）

4. 画面右下のタスクトレイに、マイクのアイコンが表示されれば起動成功です
   （見えないときは、右下の「∧」をクリックすると隠れたアイコンが出ます）


────────────────────────────────────────────
■ ステップ2：OpenAI のキーを取得する（聞き取り用）
────────────────────────────────────────────

1. ブラウザで  https://platform.openai.com/  を開く
2. アカウントを作成（またはGoogleアカウントでログイン）
3. ログイン後、こちらを開く →  https://platform.openai.com/api-keys
4. 「Create new secret key（新しいキーを作成）」をクリック
5. 表示された「sk-」から始まる文字列をコピー
   ★この画面を閉じると二度と表示されません。必ずコピーしてください★

【お支払いの設定（重要）】
   OpenAI は使った分だけの「従量課金」です。先に支払い設定が必要です。
   ・https://platform.openai.com/settings/organization/billing を開く
   ・クレジットカードを登録し、少額（例：$5〜$10）をチャージ
   ・料金の目安：音声の聞き取りは 1分あたり 約$0.006（1円弱）。
     毎日かなり使っても月に数百円程度です。


────────────────────────────────────────────
■ ステップ3：Google Gemini のキーを取得する（整形用）
────────────────────────────────────────────

1. ブラウザで  https://aistudio.google.com/apikey  を開く
2. お持ちのGoogleアカウントでログイン
3. 「APIキーを作成（Create API key）」をクリック
4. 表示された「AIza」から始まる文字列をコピー

   ★こちらは無料枠で十分使えます（基本的に料金はかかりません）★


────────────────────────────────────────────
■ ステップ4：アプリにキーを入力する
────────────────────────────────────────────

1. 右下のマイクアイコンを「右クリック」→「⚙ 設定を開く」
2. 「一般」タブの中に、
   ・OpenAI APIキー … ステップ2でコピーした「sk-…」を貼り付け
   ・Gemini APIキー  … ステップ3でコピーした「AIza…」を貼り付け
3. 「保存して閉じる」をクリック

   これで準備完了です！


────────────────────────────────────────────
■ 使い方
────────────────────────────────────────────

・録音の開始／停止 ： キーボードの  Ctrl + Shift + F9
    1回押す → 話す → もう1回押す → 少し待つと文字が入力されます
・設定を開く       ： Ctrl + Shift + F10
・マイクアイコンを左クリックでも 録音開始／停止 ができます

便利な音声コマンド：
・「定型文」と話す      → よく使う文章の一覧が出る
・「住所自動入力」と話す → 登録した住所を一括入力


────────────────────────────────────────────
■ 自動アップデートについて
────────────────────────────────────────────

新しいバージョンが公開されると、アプリ起動時に
「更新しますか？」と自動でお知らせします。
「はい」を押すだけで、最新版に自動で入れ替わります。
（手動で確認したいときは、マイクアイコン右クリック →「🔄 更新を確認」）

※あなたが入力した設定・キー・定型文などは、更新しても消えません。


────────────────────────────────────────────
■ 困ったときは
────────────────────────────────────────────

・文字が入力されない
    → マイクが正しく選ばれているか、設定の「一般」タブで確認
    → APIキーが正しく貼られているか確認
・「APIキー未設定」と出る
    → 設定画面でキーを入力して保存してください
・うまく聞き取れない
    → 少し長め・はっきりめに話してみてください

それでも解決しないときは、このアプリを渡してくれた人にご連絡ください。
